## Trường hợp 1: content-box (mặc định)
```
.box-1 {
    width: 400px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}
```
→ Chiều rộng hiển thị = 400px

→ Không gian chiếm trên trang = 470px

## Trường hợp 2: border-box
```
.box-2 {
    box-sizing: border-box;
    width: 400px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}
```
→ Chiều rộng hiển thị = 400

→ Kích thước content thực tế = 330

→ Không gian chiếm trên trang = 400

## Trường hợp 3: Margin collapse 
```
.box-a { margin-bottom: 25px; }
.box-b { margin-top: 40px; }
```
→ Khoảng cách giữa box-a và box-b = 40px

→ Giải thích tại sao KHÔNG PHẢI 65px: Do khoảng cách là phần dùng chung nên chỉ lấy cái lớn hơn, cái nhỏ sẽ trùng với cái lớn.

→ Nếu .box-a có margin-bottom: -10px và .box-b có margin-top: 40px, khoảng cách = bao nhiêu? 30px
